Menu d'insertion #pr-menu

  • Popover ancré sous le « + » cliqué ; bascule au-dessus si dépassement viewport (marge 12 px).
  • Deux groupes : Texte (H1, H2, H3, Paragraphe, Liste à puces, Liste numérotée, Étape, Encadré) et Média & schémas (Image, Vidéo, Schéma).
  • Insertion à l'index PR_INSERT_AT ; focus immédiat sur le nouveau bloc. Un diag ouvre directement l'éditeur de schéma.
  • Fermeture : clic extérieur, sélection, Échap.

Barre de mise en forme #pr-fmt

  • Apparaît uniquement sur sélection non vide dans un .pr-body ; centrée au-dessus du range (selectionchange).
  • Commandes : Gras ⌘B, Italique ⌘I, Souligné ⌘U, Barré, Lien, Surlignage (#FBEAB5), Effacer la mise en forme.
  • État actif reflété par .on (queryCommandState). Prototype = execCommand ; cible prod : modèle de document (ProseMirror / Tiptap / Lexical) avec marks équivalentes.
  • HTML autorisé dans html : b i u s a mark li br — nettoyer au collage.

Clavier dans un bloc

  • Entrée — nouveau bloc après (type conservé ; après un titre → paragraphe). ⇧Entrée — saut de ligne. Dans les listes, Entrée = nouvel item natif.
  • ⌫ sur bloc vide — supprime et remonte le curseur en fin du bloc précédent (jamais le dernier bloc).
  • Étapes : numérotation auto 1…n, remise à zéro à chaque titre.

DONNÉESModèle

Un document = liste ordonnée de blocs. Le schéma est stocké en JSON dans le bloc (pas d'image), rendu côté client.

  id: "p1",
  title: "Instruction d'une demande de projet",
  cat: "Pilotage",        // Pilotage | Conformité | Finance | Organisation | Sécurité

Glisser-déposer des blocs

  • Source : la poignée .hd[draggable] uniquement (pas le texte, pour ne pas casser la sélection).
  • Pendant le drag : bloc source en .drag (opacité .4), indicateur sur la cible selon la moitié survolée (over-top / over-bot).
  • Drop : splice source → destination avec correction d'index ; le bloc déplacé devient sélectionné ; pulse d'enregistrement.
  • Alternative clavier / a11y : Monter / Descendre dans le panneau Bloc.

Événements à journaliser

  • procedure.created · procedure.updated (autosave, debounce ≥ 1 s) · procedure.status_changed {from,to}
  • block.inserted / moved / deleted {type, index}
  • media.uploaded {kind, size} · diagram.saved {nodes, edges}
  • procedure.published {version} — déclenche notification aux abonnés et snapshot de version.

TECHNIQUEIntégration

Fichiers

  • Procedures.html — shell + vue + menu, barre de formatage, éditeur de schéma.
  • modules/procedures.js — logique (préfixes pr* éditeur, dg* schéma). Dépend de showToast().
  • styles/procedures.css — classes .pr-*, .dg-*. Tokens : --brand-ink, --brand-gold, --neutral-*, --state-danger.
  • modules/acl.js + styles/acl.css — Droits / Partager (page procedures).

Points d'attention

  • Sanitiser html côté serveur (liste blanche de balises) — le prototype fait confiance au DOM.
  • Persistance optimiste : l'indicateur « Enregistré » doit refléter la réponse réseau, pas un timer.
  • Rendu lecteur : mêmes blocs, sans contenteditable ni contrôles ; schéma via dgSVG(block, true) avec desc en info-bulle.
  • Responsive : sous 1100 px les colonnes latérales passent en tiroirs ; l'éditeur de schéma reste desktop-only.
